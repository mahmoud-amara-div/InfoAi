🧠 La pensée computationnelle

Ordinateur · D-R-A-A · Algorithmes

1. Qu'est-ce qu'un ordinateur ?

Définition

Un ordinateur est une machine électronique programmable capable de :

  • Acquérir des données (entrées)
  • Traiter ces données (calculs)
  • Stocker des informations
  • Restituer des résultats (sorties)

1.1 Schéma simplifié

📥 EntréesClavier…
→
🧠 TraitementCPU
→
📤 SortiesÉcran…
💾 MémoireRAM, disque

Un ordinateur ne pense pas !

Il exécute les instructions qu'on lui donne. C'est le programmeur qui réfléchit.

🔀 Les structures conditionnelles

Si…Alors · Si…Sinon

Introduction

Définition

Une structure conditionnelle permet de choisir un traitement selon une condition.

Les 2 formes au programme

FormeTraitementsStructure
Simple1 (ou 0)Si…Alors…FinSi
Complète2Si…Alors…Sinon…FinSi

Réservé à la 3ème

Sinon Si / elif et Selon / match sont vus en 3ème.

1. Conditionnelle simple — Si…Alors

Syntaxe

📘 ALGORITHME🐍 PYTHON
Si condition Alors
    
FinSi
 
if condition :

Exemple — Nombre positif

📘 ALGORITHME🐍 PYTHON
ALGORITHME Positif
DEBUT
    Lire (n)
    Si n > 0 Alors
        Écrire ("Positif")
    FinSi
FIN
 
n = int(input("n = "))
if n > 0:
    print("Positif")

2. Conditionnelle complète — Si…Sinon

📘 ALGORITHME🐍 PYTHON
Si condition Alors
    
Sinon
    
FinSi
 
if condition :
    
else :

Exemple — Pair ou impair

📘 ALGORITHME🐍 PYTHON
ALGORITHME PairImpair
DEBUT
    Lire (n)
    Si n Mod 2 = 0 Alors
        Écrire ("Pair")
    Sinon
        Écrire ("Impair")
    FinSi
FIN
 
n = int(input("n = "))

Exemple — Plus grand de deux

📘 ALGORITHME🐍 PYTHON

🔁 La boucle Pour

Répétition · Compteur · Boucles imbriquées

Introduction

Définition

Une boucle permet de répéter un traitement. La boucle Pour s'utilise quand on connaît le nombre de répétitions.

1. La boucle Pour

Syntaxe

📘 ALGORITHME🐍 PYTHON
Pour compteur de Vi à Vf [Pas = P] Faire
    
Fin Pour
 
for compteur in range(Vi, Vf+1, P):

Points clés

  • Compteur : variable entière
  • Pas par défaut : 1
  • Python : Vf est exclue → range(Vi, Vf+1)

Exemple — 1 à 10

📘 ALGORITHME🐍 PYTHON
ALGORITHME Compteur
DEBUT
    Pour i de 1 à 10 Faire
        Écrire (i)
    Fin Pour
FIN
 
for i in range(1, 11):
    print(i)

2. Compteur et pas

Pas

📘 ALGORITHME🐍 PYTHON
Pour i de 1 à 10 [Pas = 2] Faire
    
Fin Pour
 
for i in range(1, 11, 2):

Boucle décroissante

📘 ALGORITHME🐍 PYTHON
Pour i de 10 à 1 [Pas = -1] Faire
    
Fin Pour
 
for i in range(10, 0, -1):

Formes de range()

SyntaxeValeursUsage
range(n)0, 1, …, n-1n tours
range(a, b)a, …, b-1De a à b-1
range(a, b, 2)a, a+2, …Pas de 2
range(b, a, -1)b, b-1, …Décrément

🔑 L'essentiel

À retenir

  • Pour : répétitions connues
  • Algo : Pour i de Vi à Vf Faire ... Fin Pour
  • Python : for i in range(Vi, Vf+1):
  • Vf est exclue dans range
  • Le pas saute des valeurs
  • Pas négatif → décrémenter
  • Boucles imbriquées possibles

Syntaxes clés

# Croissante
for i in range(1, n+1):
    ...

# Avec pas
for i in range(1, 11, 2):
    ...

# Décroissante
for i in range(10, 0, -1):
    ...

# Imbriquée
for i in range(1, 6):
    for j in range(1, i+1):
        print("*", end="")
    print()

Méthodes

  1. Vérifier si le nombre est connu
  2. Utiliser range(Vi, Vf+1)
  3. Ne pas modifier le compteur
  4. end='' pour pas de retour

                Si x < cible Alors

from random import randint

            trouve = True
        else:
            if x < cible:
                print("Trop petit")
            else:
                print("Trop grand")

if not trouve:
